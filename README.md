# Expense Tracker 💰
A Python-based Expense Tracker application that helps users manage their expenses, track spending across different categories, and monitor their available balance.

## Project Overview
Expense Tracker is a Python-based application designed to help users manage their daily expenses and monitor their available balance. It allows users to organize expenses into different categories and keep track of their spending.

## Features
- Add and manage expenses.
- Organize expenses into different categories.
- Track total spending.
- Monitor available balance.
- Simple and user-friendly interface.

## Technologies Used
- Python

## How to Run
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the main Python file:

```bash
python main.py
```

## Project Purpose
This project was developed to practice Python programming, data management, conditional statements, and basic expense tracking logic.
